# Orbitali 0.2.0

Connect to `https://mcp.orbitali.ai/mcp` after the OAuth server release is deployed.
Sign in to Orbitali, select your organization, review scopes and approve or deny.
Disconnect in Orbitali Settings → Connected applications. Never paste API keys into chat.

Read the bundled manage-voice-agents skill before mutations. New agents should remain
drafts until explicitly activated. Confirm destructive changes and phone reassignment.
Remote knowledge upload accepts text content; local file paths require stdio.

This is a prepared integration package, not an approved public listing. See the release
documentation INSTALL.md and HOST-TESTS.md for tested versions and outstanding gates.
